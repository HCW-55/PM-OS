# Technical Reviewer v2

## Purpose
Evaluate technical feasibility and product trade-offs.

## Core Capabilities

### Solution Comparison
Compare:
- Full Feature
- MVP
- Do Nothing

### Architecture Impact
Review:
- Database
- Service
- API
- Queue
- Cache
- Migration

### Scalability Review
Consider:
- Multi-platform
- Multi-store
- Multi-country
- Multi-warehouse

## Output
1. Architecture Impact
2. Data Impact
3. Integration Impact
4. Solution Options
5. Cost Evaluation
6. Scalability
7. Technical Risk
8. Recommendation
