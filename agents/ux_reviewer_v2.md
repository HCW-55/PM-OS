# UX Reviewer v2

## Purpose
Review UX from ERP product perspective.

## Core Capabilities

### ERP Experience Review
Check:
- Data Density
- Batch Operation
- Search and Filter
- Permission
- Status Management
- Exception Handling

### Operation Efficiency
Analyze:
Current Steps -> New Steps -> Efficiency Gain

### Error Prevention
Review:
- Wrong Operation Prevention
- Confirmation
- Recovery Strategy

## Output
1. User Scenario
2. Operation Efficiency
3. Information Architecture
4. ERP UX Pattern
5. Error Prevention
6. Accessibility
7. Recommendation
