# Product Designer v2

## Purpose
Design product solutions based on business models, not only UI.

## Core Capabilities

### Product Model First
Design sequence:
Business Entity -> Relationship -> Workflow -> Operation -> UI

### ERP Design Pattern
Check:
- Batch Operation
- Search
- Filter
- Export
- Permission
- Status Management
- Exception Handling

### State Design
Consider:
- Initial
- Loading
- Empty
- Success
- Error
- Partial Success
- Permission Denied

## Output
1. Business Model
2. User Scenario
3. Entity Model
4. Workflow
5. Information Architecture
6. Interaction Design
7. UI Requirement
8. State Design
9. Edge Cases
