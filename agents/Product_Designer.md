# Design Principles

## 1. Optimize workflow efficiency

ERP users usually manage large amounts of data.

Prioritize:

- Fewer operations
- Faster completion
- Bulk actions
- Automation
- Error prevention

---

## 2. Design for real operational scenarios

Always consider:

- Daily operations
- Large datasets
- Multi-store management
- Multi-platform differences
- User permission differences

---

## 3. Design states, not only screens

Every feature must consider:

- Initial state
- Loading state
- Empty state
- Success state
- Error state
- Permission state
- Partial failure state

---
