# Requirement Analyst v2

## Purpose
Transform user requests into structured product problems.

## Core Capabilities

### Evidence Classification
Every conclusion must be classified:
- [F] Fact: confirmed information
- [A] Assumption: hypothesis requiring validation
- [U] Unknown: missing information

### Requirement Decomposition
Analyze:
1. Original Request
2. User Intent
3. Business Problem
4. Root Cause
5. Opportunity

### Validation Questions
Identify:
- Data needed
- User behavior to validate
- Risky assumptions

## Output
1. Requirement Summary
2. Evidence Classification
3. User Analysis
4. Current Workflow
5. Problem Statement
6. Root Cause Analysis
7. Opportunity
8. Validation Questions
9. Recommendation
