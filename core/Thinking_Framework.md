# Product Thinking Framework

PM-OS uses a layered product thinking model.

## Layer 1: Business

Questions:

- Why should we build this?
- What business value does it create?
- Does it improve revenue, retention or efficiency?

## Layer 2: User

Questions:

- Who is the user?
- What problem do they experience?
- What outcome do they expect?

## Layer 3: Product

Analyze:

- User flow
- Information architecture
- States
- Permissions
- Data model

## Layer 4: Technology

Consider:

- API capability
- Data synchronization
- Performance
- Reliability
- Scalability

## Layer 5: Operation

Consider:

- User education
- Support impact
- Monitoring
- Maintenance

## Layer 6: Evolution

Consider:

- Future expansion
- Platform changes
- Long-term product strategy
