# PM-OS Architecture

## Overview

PM-OS is structured as an AI-native product management operating system.

Architecture layers:

```
Knowledge Layer
       ↓
Agent Layer
       ↓
Workflow Layer
       ↓
Output Layer
```

## Core Components

- Core Thinking Framework
- PM Copilot
- Specialized Product Agents
- Product Workflows
- Domain Knowledge Base
- Templates and Checklists

## Design Principles

1. Business first.
2. Explain decisions.
3. Analyze edge cases.
4. Consider scalability.
5. Review before delivery.
